## **5.2 Storyteller: Daily news → script for two age levels**

**Owner:** \[ \]  
**Reviewed by:** \[ \]

### **1\. What this component does**

Takes one fact checked story from Scout and rewrites it into two bedtime story scripts, one for ages 5 to 7 and one for ages 8 to 10, following a fixed 8 to 10 page structure. Adds a parent card with one AI concept and one question to ask.

### **2\. Datasets**

| Dataset | Type | Fields we need | Access |
| :---- | :---- | :---- | :---- |
| Scout output | JSON | Title, full text, source links, confidence | After S1 and S2 |
| Hand labeled ratings | Spreadsheet | 20 stories, green / yellow / red by 2 team members | Team makes it, about 1 hour |
| Readability scale | Public standard | Flesch Kincaid grade level | Available now |
| Story structure template | Text | Cover, character, news discovery, exploration, challenge, turning point, resolution, reflection, real world facts, quiz | Team writes it |

**Do the datasets have the attributes we need?** \[TBD\]. Expected: a summary alone is too thin for a 10 page story; full text is needed.

### **3\. Hypotheses and tests**

| \# | Hypothesis | How we test | Pass if | Result | Pass? |
| :---- | :---- | :---- | :---- | :---- | :---- |
| T1 | The LLM follows the fixed story structure | Rewrite 10 stories; count pages and check each page matches its slot | 9 of 10 follow the structure |  |  |
| T2 | Rewrites add no false facts | Check each of 10 stories against the source for facts not in the source | 0 stories with added facts |  |  |
| T3 | The two age versions differ in reading level | Run both versions through a readability tool | Ages 5 to 7 at grade 2 or below; ages 8 to 10 at grade 4 or below |  |  |
| T4 | Parent cards are usable | Generate one concept and one question per story; team checks | 8 of 10 usable |  |  |

## **5.5 Playmate: Story → interaction and gamification**

**Owner:** Madhuri Kishor Dusad   
**Reviewed by:** Jinyu  
**Code:** Github

### **1\. What this component does**

Adds a 3 question quiz after each story (picture choice for ages 5 to 7, word game for ages 8 to 10), badges, streaks, a screen time limit, and parent settings. Progress is saved on the device with no child account.

### **2\. Datasets**

| Dataset | Type | Fields we need | Access |

| Storyteller output | JSON | Script, parent card, 3 key facts | After T4 |

| COPPA rules | FTC official documents | What counts as child personal data | Available now |
| Parent demand surveys | Public reports | For example, 76% of parents want schools to teach responsible AI use | Available now |

**Do the datasets have the attributes we need?** \[TBD\]. Expected: 3 key facts per story are needed to write a quiz; if missing, Storyteller must add them.

| \# | Hypothesis | How we test | Pass if | Result | Pass? |

| P1 | LLM quiz questions are correct | Generate 3 questions for 10 stories; team checks answers | 90% correct |  |  |
