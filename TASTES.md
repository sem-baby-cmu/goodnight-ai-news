# TASTES.md

## REJECT
- Never ship a template-default look: stock shadcn gray, stock blue buttons, purple gradients.
- Never use blur shadows; the only shadow is the primary button's hard `0 5px 0` edge.
- Never show anything frightening, sharp, or harshly contrasted to a child.
- Never use photos of children or stock photos.
- Never use fast, flashing, or spinning motion; bedtime pace is slow and soft.
- Never use Roof red for text or for errors; a child never sees a red X or a failure state.
- Never put text or buttons inside the 3D layer.
- Never make a child read to get anywhere.

## REQUIRE
- Use shadcn Base UI components; give character through tokens (`DESIGN.md`).
- Use paper and painted watercolor skies for everyday screens; use the Night stage for reading.
- Use Kiwi Maru for display and Nunito for UI and story text.
- Use fully round buttons and chips; cards at `22px` and `16px` radius.
- Ensure 4.5:1 text contrast, `44px` parent targets, `64px` child targets.
- Show a mock and get approval before any visual change ships.

## WHEN AMBIGUOUS
- Choose calm and warm over busy or bright; it is read at bedtime.
- Orient toward: watercolor picture books (palette, skies), pop-up books (motion), Producer's Pip scenes (character).
