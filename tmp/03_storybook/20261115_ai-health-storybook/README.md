# Dot Asks Pip About Feeling Tired

Ten-page English storybook draft for children age 5, based on `storyboard-source.md`.

## Open the book

Open `index.html` in a web browser.

- Arrow buttons, keyboard arrow keys, dots, and touch swipes change pages.
- The sparkle button reveals three clickable areas on every page.
- The music button turns small interaction sounds on or off.
- Story text remains in HTML rather than being baked into the artwork.

## Contents

- `index.html` — interactive storybook reader.
- `pages/page-01.png` through `pages/page-10.png` — final 1672 × 941 page illustrations.
- `storyboard-source.md` — source storyboard and production specification.
- `_working/` — superseded generated drafts kept for visual audit.

## Current draft status

This draft contains ten finished full-page illustrations and a working reader with navigation, three automatic micro-effects, and three clickable feedback areas per page. The click feedback is implemented in the reader. Production-ready character/object frame-by-frame transparent PNG layers described in the storyboard remain a separate animation-asset pass.

## Image-generation prompt set

All page prompts used the `illustration-story` production brief: preserve the supplied Pip, Dot, and Fenn character designs; match the supplied hand-cut paper-collage page references; create a 1672:941 landscape illustration; reserve the lower portion as blank warm cream text space; avoid baked-in text, logos, watermarks, diagnoses, medication, personal health data, and frightening medical imagery. Page-specific scenes and safety messages follow `storyboard-source.md`.
